# 🛡️ SENTRYNET

### Phishing Awareness & Cybersecurity Training Platform

SENTRYNET is an interactive cybersecurity awareness platform designed to educate users about phishing attacks, fake websites, social engineering, suspicious emails, and common online security threats.

The platform uses interactive examples, simulated scenarios, visual demonstrations, and quizzes to help users recognize phishing attempts and develop safer online habits.

## 🎯 Project Objective

Phishing is one of the most common forms of cybercrime and relies heavily on human error rather than technical vulnerabilities.

SENTRYNET aims to make cybersecurity awareness simple, interactive, and practical by helping users understand:

- How phishing attacks work
- How attackers manipulate human psychology
- How to identify suspicious emails
- How to detect fake websites and URLs
- How social engineering attacks work
- How to respond safely to suspicious messages
- How to avoid revealing sensitive information

---

## ✨ Key Features

### 📧 Phishing Email Awareness
Interactive fictional email examples demonstrate common phishing indicators such as:

- Urgent requests
- Suspicious senders
- Fake verification links
- Spelling and grammar mistakes
- Requests for passwords or OTPs
- Suspicious attachments

### 🌐 Fake Website Detection
Learn how to identify suspicious websites by analyzing:

- Domain names
- Typosquatting
- Lookalike domains
- Suspicious URLs
- URL paths
- HTTPS limitations
- Redirect risks

### 🧠 Social Engineering
Understand common psychological manipulation techniques used by attackers, including:

- Urgency
- Fear
- Authority
- Trust
- Curiosity
- Impersonation

### 🎭 Real-World Scenarios
Interactive fictional scenarios allow users to choose the safest response to suspicious situations.

### 🚩 Red Flag Detection
Learn about common warning signs that should immediately raise suspicion.

### 🛡️ Cybersecurity Safety Tips
Practical security recommendations to help users protect their:

- Accounts
- Passwords
- Personal information
- Financial information
- Devices

### 📝 Interactive Quiz
Test your understanding of phishing and cybersecurity awareness through an interactive quiz.
